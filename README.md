# Android Source Archive

A community archive of Android custom ROM sources, including device trees,
common trees, kernels, vendor sources, and ROM-specific components.

## Organization

Sources are organized by Android version:

- Android 13
- Android 14
- Android 15
- Android 16

Each Android version contains:

- `LineageOS/`
- `crDroid/`

Inside those folders, sources are organized by device codename.

## Sources & Attribution

All archived third-party source code remains under its original license.

Original copyright notices and license files are preserved whenever possible.

Each archived device should include information about:
- Original repository
- Upstream branch/tag/commit
- ROM and version
- Android version
- Original license
